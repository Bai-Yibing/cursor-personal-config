# 视觉 SLAM 与占据建图方法论

产物写入 `<maps_output>/<session>/`。先确定传感器拓扑与同步，再调算法参数。

## 1. 问题定义

本类问题包括：位姿跟踪丢失、地图拖尾/双墙、闭环失败、开环投影造假高覆盖、无纹理或透明表面导致的几何空洞。不属于单一参数细调，而是传感、前后端分工、验收指标选择错误。

## 2. 不变量 / 第一性原理

- **信息论**：纯视觉需要可重复特征与时间同步；无纹理/玻璃缺少几何约束。
- **前后端分离**：跟踪（前端）供位姿；建图/闭环（后端）消费位姿与观测。参数不可混用。
- **开环投影不能验证地图**：无位姿约束的投影可提高覆盖率但不改变拓扑错误。
- **重置不对称**：防止位姿跳变 ≠ 能继续探索；长失锁后随意 reset 易造成米级错位。

## 3. 架构/选型决策树

| 约束 | 优先路径 | 避免 |
|------|----------|------|
| 手持 2D 占据 | 双目/IR + IMU 做 VO；深度进栅格后端 | 把 RGB 对齐深度当主路径而同步不稳 |
| 移动平台 2D | 扫描匹配 / 位姿图优化后写图 | 开环里程计直接当真图 |
| 无纹理/玻璃 | 几何主图 + 语义旁路（见 semantic skill） | 把外观 mask 注入特征匹配 VO |
| 环境光纹丰富 | 特征 VO + 深度栅格（快速原型） | 期望强后端优化而不做闭环 |
| 有稳定 2D 激光 | 2D 激光 SLAM + 导航衔接 | 用纯视觉硬替代激光约束 |
| 多传感器长时程 | RGB-D / 多模态 SLAM 类 | 未分配资源前堆高分辨率 |

算法类别只作权衡，不绑定单一产品。

## 4. 标准操作流程 SOP

1. **传感器拓扑**：确认双目/IR、IMU、深度流、时间戳与外参一致。
2. **前端参数**：仅改跟踪/里程计相关项；出现 `Ignored ...` 类日志视为硬失败。稀疏近平面扫描（单层雷达）点对面 ICP 可能开局即无 quantile、odom 公里级；对照圈应单变量改点对点。室内地面机器人再单变量开平面约束（Force3DoF 一类），否证高度被抬到米级。多线稠密云才优先点对面、6DoF。开源多线/固态雷达演示不能当稀疏单层的验收。紧耦合 LIO 不要信任仓库 C++ 默认：以厂商同传感器 launch 为准覆盖「IMU 是否进 KF」和体素；默认把 IMU 当输入 + 粗体素时，匹配弱会按 `½at²` 开环积分。雷达系云与机体已变换云（`*_base`）只能选一种进 LIO，禁止第二套雷达驱动。**站立稳 ≠ 走动稳**：先做静止位移门再短走对照本体里程计；走动千米级则回退本体 odom，不要用站立毫米当走圈位姿。
3. **后端参数**：栅格、闭环、深度融合单独调整。
4. **走动 SOP**：慢起步、保留前向纹理、沿可重复路径回访造环。
5. **会话结束**：导出 lost%、loops、path/span、同步滞后与环境事件到 `<maps_output>/<session>/`。
6. **失锁政策**：短失锁可续扫；长失锁停步回纹理区；禁随意 soft_reset 追探索。

## 5. 度量与门禁

分两张表验收，禁止用一张表替代另一张：

**A. 位姿 / VO KPI**

| 指标 | 意义 | 门禁判断 |
|------|------|----------|
| lost% / 跟踪丢失时长 | 前端健康 | 持续升高→先查同步/曝光/运动 |
| recovered? | 失锁后能否重锁 | 长失锁未 recovered → 拓图冻结；防跳变 ≠ 能继续扫 |
| loops | 闭环质量 | 中后段接近 0 → 漂移 smear 风险 |
| path/span | 须拆开看 | 积分路径长而节点包围盒很小=原地转；ICP 丢失则 span 虚高 |
| sync_lag / no_odom | 时间与里程计 | 必须在调参前消除 |

**B. 占据 / 地图观感 KPI**

| 指标 | 意义 | 门禁判断 |
|------|------|----------|
| known% / 覆盖率 | **辅助** | 不可单独验收；开环投影可造假 |
| 组装点云跨度 | **辅助** | ICP 丢失后跨度可虚高 |
| 节点平面包围盒 | **验收** | 与积分 path 对照；path 长而 AABB 小不是房间图 |
| 占用/已知比 | **辅助** | 过半格子是障碍多为飞点；**过低也不是成功**（扇骨/射线、自由格多但无墙） |
| live `/map` | 在线拖影 | 旋转中常 smear；验收用会话结束的优化 DB/PCD |
| 墙体/家具块状度 | 可导航性 | 目视无双墙、桌子不镂空 |
| 语义差分（若启用） | 旁路是否真写入 | 见 `semantic-occupancy-fusion`；网格须对齐 |

验收看闭环后墙体一致性与可导航性。**长扫 VO 很好、占据仍碎**时，优先查占据持久化（扩边清票、射线清空），不要先怪扫法。

## 6. 故障分类学

| 症状 | 可能原因 | 否证测试 |
|------|----------|----------|
| 中好后差 / smear | 闭环丢失、漂移累积 | 对齐时间轴看 loops 与 lost 事件 |
| 双瓣团块地图 | 开环投影 | 关闭开环投影，比对位姿图约束 |
| 大量 Ignored 参数 | 前后端参数灌错节点 | 分离 launch 参数集 |
| 白墙全空 | 纯视觉物理上限 | 改传感/VIO/语义旁路，不再堆同一 VO |
| features 高 + inliers≈0 | 匹配/反射崩，非「没点」 | 查曝光/反射/纹理区；勿指望分割喂 VO |
| 失锁后跳变 | 不当 reset | 复现路径上禁 reset，改人工回纹理区 |
| 无跳变但地图停更 | hold 过期后冻结、未 recovered | 停扫回纹理或可恢复策略 |
| VO KPI 好、图仍碎 | 占据层问题 | 转查语义扩边/几何多孔，分表验收 |

## 7. 反模式与理由

| 错误本能 | 为何失败 | 正确做法 |
|----------|----------|----------|
| 先加分辨率/细栅格 | 资源与噪声同步恶化 | 先降 Range/Decimation，再谈细化 |
| 用 known% 宣布达标 | 开环可造假高值 | 看 loops + 目视拓扑 |
| 用 live 占据图验收 3D | 跟踪中投影会拖影 | 会话结束导出优化点云与位姿图 |
| 用组装云跨度当路程 | ICP 丢失会把 span 拉到几十米 | 对照节点 AABB、ratio 与真实走动 |
| 用积分 path、闭环边或 `mapped_with_loop` 宣布扫完房间 | 家具口袋里转圈也能积出闭环和百米 path | 同时看节点平面包围盒、墙线、占用/已知比 |
| 用占用/已知低宣布 2D 变干净 | 单帧切扫描会画出扇骨，自由格很多墙却没有 | 表 1 看预览墙线；离线整帧投影只能对照位姿，不能代替 live `/map` |
| 把扫描匹配里程计当室内真值 | 同袋投影可涂满无墙，而本体里程计能画出外框 | 用接收时间对齐后对照投影 occ/m²；header 时钟可能差数分钟 |
| 稀疏单帧直接切 LaserScan 做 2D SLAM | 每圈命中过少，栅格是射线不是墙 | 先在 odom 滑动积帧再切扫描 |
| 深度+激光一起写占用栅格 | 椅腿/飞点永久占格，占用比虚高成盐椒 | 2D 占用以激光为主；深度只做外观/闭环 |
| 用开源多线演示验收机载稀疏雷达 | 每帧点数差一个数量级，观感不可比 | 先对传感器密度分类，再选积帧+2D 或换雷达 |
| 在障碍口袋里加自动遥控时长 | path 拉长、z 漂、图 smear，覆盖几乎不涨 | 人放到开阔处沿边慢走；同一口袋停测 |
| 两套 SLAM 抢同一 `/scan` | 里程计与 2D SLAM 互相饿死或 smear | 积帧扫描用专用话题名 |
| 预览空白当画布坏了 | 常是 `/map` 未发、odom 全零 | 查 `waiting_map`、首秒 lost、库节点数 |
| 四宫格中间一小块当四个视频没拼 | 小图未放大贴在格子左上 | 抽帧看单文件分辨率与 `_fit` 缩放 |
| seg 进 VO | 破坏点对应 | 语义只进占据旁路 |
| 失锁后边走边 reset | 易米级跳变 | 停步或结束会话重扫 |
| 用仓库默认当厂商 LIO 已适配 | 官方 launch 常关 IMU-as-KF；默认 true + 粗体素站立可飞百米 | 对照官方同雷达 launch，覆盖 IMU 输入开关与体素后再上电 |
| 站立位移小就宣布 LIO 可走圈 | 走动匹配退化仍可千米级，本体里程计可仍停在原地 | 走动对照本体 odom；发散即停 LIO |
| 用未过墙线的房间 `/map` 做 NavigateToPose | 扇骨/射线不是可导航拓扑 | 表 1 过墙后再绑全局规划；跟人用滚动 odom costmap |
| 跟随侧发恒等 `map→odom` 同时开 toolbox | 抢 TF，live `/map` 与局部规划错位 | 有 slam_toolbox 时禁止恒等静态 TF；仅无图模式才发 identity |
| 对滑动积帧点云做全局闭运算当占用图 | 稠密云把扫过体积涂实，占用比可到九成，房间轮廓消失 | 局部机体栅格可填椅缝；全局预览用 SLAM `/map`；显示加粗不得写回栅格 |
| 按连通域跨度对 live `/map` 胀家具 | 稀疏墙也是碎点，几乎全被当成小团胀开 | 墙/家具分不开时不要形态学修图；只做预览膨胀或局部代价图 |
| 在已出墙的匹配参数上再收严并降 `min_pass_through` | 匹配拒绝变多后按漂航向重绘同一堵墙 | 对照已过墙线的基线；一次只改一个匹配/占格键 |
