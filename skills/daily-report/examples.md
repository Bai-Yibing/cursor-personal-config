# 日报示例（行文风格参考）

结构为「今日总结 / 存在问题 / 明日待办」。总结用第一、第二、……分条，后两块用 1. 2. ……。条数跟当天内容走，一二三只是举例。一条一事：并行交差线分开写。写前先扫当天全部工作记录。每条写满目标、结果和证明边界。

```text
20260615
今日总结
第一，把撞墙原因查清楚了。一开始怀疑是激光避障坏了，但日志显示扫描一直正常。真正的问题有两类：一是导航恢复时会盲退，身后没地图就容易后腿撞墙；二是定位用的视觉里程计和狗腿里程计经常对不上，尤其在白墙大厅，狗在走但视觉几乎不动，地图里机器位置是错的，导航以为前面能走，实际就蹭墙或撞墙。另外还有一次典型故障：地图到里程计的坐标变换只发了一次就停了，探索模块报坐标超时，地图九成以上都是未知区。
第二，做了地图与里程计融合，并接到探索流程里。新加了一个融合节点：每秒五十次刷新地图坐标、狗在走而视觉不动时慢慢用腿程修正位置、视觉重定位跳变时吸收掉。狗模式下调视觉不再单独发静态地图变换，改由融合节点负责。同时加强了启动前清进程（避免误杀探索脚本）、位姿跳变时暂停涂图、监督节点在定位异常时取消导航目标。
第三，今天跑了很多轮实机（十余次）。上午几轮狗几乎不动，未知区九成五以上。下午去掉盲退、调膨胀参数后有改善。融合方案第一轮测了约十五分钟：坐标外推和越界问题消失，狗走了约一米五，地图已知区约一成二，融合吸收了九次视觉跳变。融合第二轮更好：约十七分钟，狗走了约五米，已知区约一成二，是今天最好的一轮；监控五分钟里定位稳定、扫描正常、无盲退。后来又测了一轮（已改暖机不再后退、限速接入），暖机确认无后退，但这轮狗几乎没动，坐标外推又变多，会话不完整，原因待查。不要把最好一轮五米写成覆盖已达标。

存在问题
1. 白墙、纹理少的地方，视觉定位仍不稳，经常丢定位，探索会周期性暂停。地图扩展还是慢，最好一轮已知区也只有一成多。
2. 同一天的融合测试好坏差别大，有一轮很好、有一轮几乎不走，需要对比查原因。会话结束时有时存不下最终地图。
3. 贴墙、窄道避障还要在更长测试里验证。暖机倒车已改，实机长时间无后退仍待再确认。

明日待办
1. 对比今天两轮融合测试差在哪里（融合日志、坐标时间、启动顺序）。
2. 换纹理和障碍更丰富的区域，再跑完整十五到三十分钟，看地图能否扩到两成以上、狗能否稳定走五米以上。
3. 确认暖机和限速修改后实机无大幅后退；结束流程改为先存图再停节点。
```
